# Student Management System

一个使用 C++ 编写的命令行学生管理系统。

## Features

- Display all students
- Find a student by ID
- Add a student
- Update a student's score
- Remove a student
- Save student data to a file
- Load student data from a file

## Project Structure

- `Student.h` / `Student.cpp`: Student class
- `StudentManager.h` / `StudentManager.cpp`: Student management logic
- `main.cpp`: Menu and user interaction

## Build Environment

- Language: C++
- IDE: Visual Studio
- Platform: Windows

## How to Run

1. Open the solution in Visual Studio.
2. Build the project.
3. Run the program.
4. Follow the menu prompts to manage students.
